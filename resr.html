(Case study)

Research Nest.

AI-powered research paper management and question extraction system.

June 2024Flask · Python · AI · NLPTeam project

(01) — Overview

The
idea

ResearchNest helps students and researchers manage academic papers and pull out the insights that matter. It processes research documents, extracts key information, and generates questions that improve understanding and retention.

View on GitHub

(02) — Features

What it
does

Document Upload

Upload research papers in PDF, DOCX and more. Content is automatically processed and indexed for quick retrieval.

AI-Powered Analysis

Natural language processing extracts key concepts, summaries and relevant questions from the research material.

Smart Search

Semantic search finds specific information across every uploaded document.

Question Generation

Automatically generates questions from the content to test understanding and support learning.

(03) — Build

How it's
made

A modern stack chosen for scalability, performance and a good user experience.

Frontend

  • HTML5, CSS3 and JavaScript (ES6+)
  • Responsive, mobile-first design
  • Interactive UI components with smooth animations

Backend

  • Python with Flask
  • SQLAlchemy for database operations
  • RESTful API architecture
  • JWT-based authentication

AI / ML

  • Natural Language Processing for text analysis
  • Transformer models for question generation
  • Text summarisation
  • Named Entity Recognition for key information extraction

(04) — Challenges

Hard
parts

Accurate Text Extraction

Extracting clean, structured text from various document formats while preserving the original formatting and structure.

Solution: A multi-layered extraction pipeline using PyPDF2 for PDFs and python-docx for Word documents, with custom post-processing for edge cases.

Efficient Question Generation

Creating meaningful, contextually relevant questions from academic texts.

Solution: Fine-tuned a transformer-based model on academic texts, plus a rule-based layer to keep question quality and relevance high.

Scalability

Handling large documents and many concurrent users without performance degradation.

Solution: Asynchronous processing with Celery and Redis, along with database optimisation.

impact
